# Product

Comixa Desktop is the desktop companion app for Comixa, an original local-first comic reader.

## MVP 1

MVP 1 focuses on the Local Desktop Reader Core:

- Select local folders.
- Scan local comic files.
- Read CBZ/ZIP archives and PDF files.
- Show a library with covers.
- Open a reader screen with page navigation.
- Support zoom and fit modes.
- Track reading progress.
- Store bookmarks.
- Persist local state in SQLite.

## Product Principles

- Local-first by default.
- Fast and quiet desktop experience.
- Clear separation between reader, library, and persistence logic.
- Windows-first polish without closing the door on Linux and macOS.

## Out Of Scope For MVP 1

- Cloud sources
- SMB or WebDAV
- CBR/RAR
- OCR
- AI translation
- Network sync
